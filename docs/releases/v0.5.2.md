# Fireworks v0.5.2

健康检查语义收敛：**健康只以 head 为准、属任务层面**；节点仅保留容器状态。

## 变更

- 健康判定仅取 **head** 容器（worker 无健康端点，不参与；worker 退出仍由「容器全部 exited → stopped」兜底）
- 新增任务层面 `tasks.health` 列（幂等迁移），监控/健康检查按 head 聚合写入：健康 / 异常 / 检查中 / 未配置
- 任务详情「健康状态」展示在信息卡；容器表恢复仅状态列
- 移除节点级 `task_nodes.container_health` 列（启动时幂等迁移自动清理）

## 升级

- 控制面升级到 `0.5.2`；启动自动迁移（加 `tasks.health`、删 `task_nodes.container_health`，幂等且保留数据）
- 节点 Agent 建议随升（旧 Agent 健康显示「未配置」，仍兼容）
- 无需手工迁移；升级前建议备份 `fireworks-db` 卷

完整变更见 [CHANGELOG](https://github.com/skymaze/Fireworks/blob/v0.5.2/CHANGELOG.md)。
