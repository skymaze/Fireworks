# Fireworks v0.11.0

0.10.0 补齐了模型版本化重构（增量更新、版本切换、worker 差量直传、GC），这一版集中修复该批功能在真实集群下暴露的完整性问题：缺失清单截断、强制刷新提前完成、重启后续传误判、版本钉扎误报，以及两个前端问题（i18n 语法导致启动覆盖层、节点表格窄视口折行）。

## 变更

- **差量直传截断回退**：Agent 返回的缺失文件清单上限 500，超出时新增 `truncated` 标志，控制平面回退全量直传，不再按截断子集补出一个永远不完整的快照。
- **「更新到最新」以远端为准**：强制刷新任务的目标锁定为解析到的远端最新 commit，监控等待新版本就绪后才放行/分发。
- **重启续传按目标版本**：后端重启恢复进行中的下载任务时按 `job.sha`（任务目标 commit）判定完整性并续传，与激活版本脱钩。
- **版本钉扎精确校验**：按指定 commit 发布/分发时，控制平面就绪校验只认该 commit，不被漂移后的激活版本误导。
- **前端**：修复 `@{sha}` 非法 i18n 语法导致的启动崩溃；节点管理表格改为单行单元格 + 最小宽度 + 横向滚动，窄视口不再折行。

## 升级

- 控制面与前端升级到 `0.11.0`。
- **节点 Agent 建议重部署到 `0.11.0`**：新版 Agent 在缺失清单超过上限时返回 `truncated` 标志，这是本轮完整修复的一部分；缺失数不超 500 的场景新旧 Agent 行为一致，旧 Agent 不升级仍可用。
- 无新增数据迁移。

完整变更见 [CHANGELOG](https://github.com/skymaze/Fireworks/blob/v0.11.0/CHANGELOG.md)。
