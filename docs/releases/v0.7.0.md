# Fireworks v0.7.0

镜像与节点管理大幅补强：节点支持多选/全选与批量操作，镜像管理暴露真实版本（registry digest）并能在同一 tag 指向新构建时自动识别重拉；任务/模型/镜像列表的变更操作补齐行级 loading 与防重入，双击不再造成重复误操作。

## 变更

- **节点批量化（新增）**：节点列表支持多选/全选（表头三态勾选），可对选中节点批量「重装/升级 Agent」或「批量初始优化」——并行执行、逐节点返回结果互不影响；批量优化自动跳过已优化节点，结果以弹窗逐项展示成功/失败/跳过原因。
- **镜像真实版本（新增）**：镜像传输任务与控制平面归档均显示 `registry digest`（真实构建标识，区别于内部归档指纹），hover 可看完整值；每个本地归档新增「检查更新」，一键比对 registry 当前 digest 并提示「已是最新 / 有新构建 / 本地未记录」。
- **同 tag 新构建自动更新**：同一 tag 在 registry 上被重新构建（tag 漂移）后，重新拉取/分发会自动识别并强制重拉（不再需要手动「重新拉取」），各节点随之加载新版本；`image_transfers` 新增 `registry_digest` 列记录真实版本，旧归档首次分发自动校准重拉一次。
- **列表操作防误触（修复）**：任务/模型/镜像列表的删除、暂停/继续、取消、重试等操作补齐行级 loading 与防重入守卫（同一行同时只允许一个变更操作）；修复任务列表删除失败无提示、以及删除请求可被连点重复发起的问题。任务详情操作按钮补防重入兜底。

## 升级

- 控制面升级到 `0.7.0`：含一条幂等数据迁移（启动时自动为 `image_transfers` 增加 `registry_digest` 列），节点 Agent 无需重部署。
- 升级后首次分发旧归档镜像时，因无法确认其内容是否为当前 tag 版本，会自动重新拉取一次并补齐版本记录（仅一次）。

完整变更见 [CHANGELOG](https://github.com/skymaze/Fireworks/blob/v0.7.0/CHANGELOG.md)。
