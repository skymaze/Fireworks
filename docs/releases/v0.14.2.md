# Fireworks v0.14.2

0.14.2 聚焦推理性能图表的可读性：Decode 与 Prefill 不再同轴混排，Decode 吞吐改为堆叠柱状图（多模型占比可比较、空白时段真实可见），并补齐 TPOT 与 p50/p95 时延展示。

## 变更

- **Decode / Prefill 分图**：Token 吞吐图不再把两者画在同一根 y 轴上——Prefill 并行计算速率可达数万 tok/s，而 Decode 逐 token 串行通常仅数百 tok/s，同轴时 Decode 几乎不可见；且 Prefill 速率受 prefix cache 影响，数值不具可比性。现在 Decode 吞吐独立成图，Prefill 改为「输入 token 体量」图展示输入侧负载，「Prefill 峰值」卡片注明「受 prefix cache 影响，仅供参考」。
- **堆叠柱状图**：Decode 吞吐与输入 token 体量均改为堆叠柱状图。多个任务/模型在同一时间桶内上下堆叠，各模型占比一目了然；无流量的时间桶不画柱，不再被折线/面积图“平均”出虚假的连续输出。
- **时延 p50 / p95 与 TPOT**：TTFT / E2E / TPOT 以 p50（实线）+ p95（虚线）展示；TPOT（每输出 token 时延）此前由 Agent 采集但未透传，本版本打通上报链路并在详情页展示。

## 升级

- 控制面与前端升级到 `0.14.2`。
- 节点 Agent 仅版本号同步（无行为变更），无需重部署节点。
- 无新增数据迁移。

完整变更见 [CHANGELOG](https://github.com/skymaze/Fireworks/blob/v0.14.2/CHANGELOG.md)。
