# Fireworks v0.9.0

模型管理系统启动版本化重构（阶段一）：HF 仓库本身就是 git，每个 revision 解析后是唯一的 commit sha——现在 sha 被落库并在界面展示，下载/分发的版本第一次可见、可追溯；同时本地缓存改为 git 式多版本共存，为增量更新与版本切换打基础。

## 变更

- **模型版本元数据（新增）**：任务与本地缓存记录解析后的 commit sha；下载/分发任务行与本地缓存卡片显示版本短 sha（如 `@2a7f3d1`），本地缓存可展开查看版本列表（短 sha / 大小 / 是否完整）并标记当前激活版本。
- **多版本共存（新增）**：重复下载/更新不再清除历史版本，`snapshots/<sha>` 与 `trees/<sha>.json` 按 commit 全部保留，切换/回滚零成本；就绪与完整性校验改为按 `refs` 指向的激活版本判定，历史克隆不再掩盖当前版本缺失。
- **模型页面状态修复**：分发中的模型此前一律显示「下载中」，现在发送/同步阶段按实际阶段展示；有进行中传输的模型删除按钮正确禁用。
- **失败任务重试修复**：重试改为就地复用原任务（同一 ID、断点续传），不再出现「旧失败 + 新下载」两条并存，避免误以为又失败一次。
- **发布不破坏已完整缓存**：目标版本缓存完整时直接复用并分发，不再破坏性重下载；下载改为所有文件就位后才写布局，中途失败不丢数据；本地缓存不完整时新增「补全」入口，断点续传补齐。

## 升级

- 控制面与前端升级到 `0.9.0`，节点 Agent 无需重部署。
- 含一条启动时幂等数据迁移（`model_downloads.sha` 列），旧任务 sha 为空，下次下载/分发运行时自动回填。

完整变更见 [CHANGELOG](https://github.com/skymaze/Fireworks/blob/v0.9.0/CHANGELOG.md)。
