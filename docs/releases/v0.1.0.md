# Fireworks v0.1.0

Fireworks 的首个公开版本，为 NVIDIA DGX Spark（GB10）集群提供从节点接入、高速网络配置，到模型分发和推理任务运行的一体化 Web 控制平面。

## Highlights

- 节点通过 SSH 一键接入，Agent 使用离线 wheelhouse 部署并由 systemd 托管。
- 自动探测和事务化配置四条 RoCE rail，支持物理链路、IP 冲突、GID 与跨节点连通验证。
- 模型和镜像在控制平面只下载一次，再通过 head 和高速网络并行分发到 worker。
- 配方商店支持远端分支发现、同步、恢复与本地独立安装。
- 任务支持节点级 head/worker/rank 分配、生命周期操作、连续日志、健康检查和性能压测。
- 总览展示物理拓扑、GPU 资源，以及吞吐、TTFT、KV Cache 和并发基准指标。

完整变更见 [CHANGELOG](https://github.com/skymaze/Fireworks/blob/v0.1.0/CHANGELOG.md)。

## Install

发布流水线会把同一套多架构镜像同时推送到 GHCR 与阿里云 ACR：

```bash
FW_IMAGE_TAG=0.1.0 docker compose -f docker-compose.prod.yml pull
FW_IMAGE_TAG=0.1.0 COOKIE_SECURE=0 docker compose -f docker-compose.prod.yml up -d
```

`COOKIE_SECURE=0` 仅用于本机或可信内网的纯 HTTP 访问；HTTPS 部署请保持默认安全设置。

## 开发阶段数据

v0.1.0 是首次发布，数据库直接按最终模型创建，不提供开发阶段数据库的升级保证。曾运行源码快照的环境应使用新的 `fireworks-db` 卷，并重新接入节点；模型和镜像文件可按需保留或重新获取。

## Notes

- 中国大陆 compose 文件默认从阿里云镜像仓库拉取，发布标签触发的 GitHub workflow 会同步推送同名 `0.1.0` 镜像。
- Fireworks 会修改所选节点的高速网络配置。生产接入前请确认布线、管理网访问和现有 Netplan 备份策略。
