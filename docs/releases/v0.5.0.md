# Fireworks v0.5.0

任务健康检查改为**以 docker compose 声明 healthcheck 为准**，不再写死 `VLLM_PORT + /v1/models`（配方换框架/端口不再误判）。

## 变更

- 配方在 compose 声明 `healthcheck:` 即生效：容器 `healthy` → 任务运行中；`unhealthy` → 任务错误；健康类错误可随容器转 `healthy` 自动恢复
- 未声明 healthcheck 时健康状态显示「**未配置**」，不做任何判定
- 任务详情容器表新增「健康」列（健康/异常/检查中/未配置）
- Agent `compose_ps` 暴露容器 Health；移除 vLLM 探测兜底代码

## 升级

- 控制面升级到 `0.5.0`；启动时自动迁移 `task_nodes.container_health` 列（幂等）
- 节点 Agent 建议随升（旧 Agent 健康显示「未配置」，仍兼容）
- 无任务语义破坏性变化，无需手工迁移；升级前建议备份 `fireworks-db` 卷

完整变更见 [CHANGELOG](https://github.com/skymaze/Fireworks/blob/v0.5.0/CHANGELOG.md)。
