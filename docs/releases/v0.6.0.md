# Fireworks v0.6.0

配方商店交互升级：分支切换上移到工具栏下拉框，并修复同步状态串源、厂商筛选无法改回「全部厂商」两个问题。

## 变更

- **工具栏分支快捷切换**：源选择器旁新增分支下拉框，选中即切换分支并重新同步目录；分支列表按源在会话内缓存。「源设置」弹窗精简为只读的 URL / 分支信息与删除源。
- **修复同步状态串源**：同步 loading 绑定到正在同步的源本身，切换配方源时不会把转圈状态带到下一个源。
- **修复厂商筛选**：选中厂商后再也打不开下拉框、无法改回「全部厂商」的问题（reka-ui Combobox 空字符串 value 渲染崩溃），现已修复。

## 升级

- 控制面与前端升级到 `0.6.0`；**无数据库迁移**，节点 Agent 无需重部署。
- 分支切换沿用原有语义：切换后重新同步目录，已安装的本地配方不受影响。

完整变更见 [CHANGELOG](https://github.com/skymaze/Fireworks/blob/v0.6.0/CHANGELOG.md)。
