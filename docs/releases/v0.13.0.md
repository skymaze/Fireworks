# Fireworks v0.13.0

0.13.0 为节点管理补齐镜像管理：节点详情页此前只有「节点模型」，节点上的 Docker 镜像没有独立入口。本次新增「节点镜像」卡片，可查看节点上的全部镜像并逐个删除，与模型管理对称。

## 变更

- **节点镜像列表**：节点详情页新增「节点镜像」卡片，通过 SSH 直接列出节点上的全部 Docker 镜像——每个 `repo:tag` 一条（同一镜像多 tag 分行），并显示大小与创建时间；`<none>` 悬挂镜像以镜像 ID 展示，可直接删除。已有节点无需升级 Agent 即可使用（与「删除节点时清理镜像」同一条 SSH 通道）。
- **单个镜像删除**：每个镜像提供删除按钮，调用 `docker rmi` 删除该标签/镜像。镜像被运行中容器占用时 docker 会拒绝删除并返回明确错误（不会强删破坏运行中的任务）；删除镜像传参经过白名单校验，防止 shell 注入。
- 删除节点时的「清理镜像」逻辑保持不变，二者互不影响。

## 升级

- 控制面与前端升级到 `0.13.0`。
- 无节点 Agent 变更，无需重部署节点。
- 无新增数据迁移。

完整变更见 [CHANGELOG](https://github.com/skymaze/Fireworks/blob/v0.13.0/CHANGELOG.md)。
