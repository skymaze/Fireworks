# Fireworks v0.14.3

0.14.3 修复首页推理图表（Decode 吞吐、输入 token 量）在时间轴上出现的悬空柱：堆叠柱状图的系列基线曾被 VLLM 预处理错误对齐，导致柱子底部离开基线。

## 变更

- **首页推理图表悬空柱修复**：首页「Decode 吞吐」与「输入 token 量」堆叠柱状图在时间轴上出现悬空柱——ECharts 当前在时间轴上做堆叠时按系列数据索引对齐基线，多个任务有数据的时间桶不一致时，后绘制的系列会把前一任务**不同时刻**的值当作堆叠起点，柱子底部离开基线。现在各任务系列先按全局时间桶对齐（缺失桶补空），再交给 ECharts 堆叠，柱子始终从基线起量，空白时段保持无柱。
- 无其他功能变更。

## 升级

- 控制面与前端升级到 `0.14.3`。
- 节点 Agent 仅版本号同步（无行为变更），无需重部署节点。
- 无新增数据迁移。

完整变更见 [CHANGELOG](https://github.com/skymaze/Fireworks/blob/v0.14.3/CHANGELOG.md)。
